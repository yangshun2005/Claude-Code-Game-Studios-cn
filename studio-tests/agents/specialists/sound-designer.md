# Agent 测试规范：sound-designer

## Agent 摘要
领域：SFX 规格、音频事件、混音参数和音效类别定义。
不负责：音乐创作方向（audio-director）、音频系统的代码实现。
未分配门禁 ID。

---

## 静态断言（结构性）

- [ ] `description:` 字段存在且领域明确（引用 SFX / 音频事件 / 混音）
- [ ] `tools:` 列表包含 Read、Write、Edit、Glob、Grep — 不包含引擎代码执行工具
- [ ] 模型层级为 `inherit` — frontmatter 中 `model:` 精确为 `inherit`（层级说明：`.claude/docs/model-tiers.md`）
- [ ] Agent 定义不声称对音乐方向或音频代码实现拥有权限，并指明 `audio-director` 为音乐方向和作曲的负责人

---

## 测试用例

### 用例 1：领域内请求 — 输出恰当
**输入：** "为剑挥砍攻击创建一份 SFX 规格。"
**预期行为：**
- 产出完整的 SFX 规格表，包括：
  - 描述、参考音效、频率特征和时长
  - 音量范围和空间属性
  - 变体方案：变体数量、音高随机化范围（例如 ±8%）和轮询行为
  - 音频事件条目：触发条件、优先级、并发上限和冷却时间
  - 混音总线分配（例如战斗 SFX 总线）
- 若项目已建立音频命名规范，事件名遵循该规范（例如 `sfx_combat_sword_swing`）
- 不创建音频文件，不编写引擎代码；写入文件前先询问

### 用例 2：领域外请求 — 正确重定向
**输入：** "为森林关卡创作一段循环环境音乐。"
**预期行为：**
- 不产出音乐创作方向或音乐简报，也不创建音频本身
- 明确说明音乐方向属于 `audio-director`
- 将请求重定向至 `audio-director`
- 其替代性提供的内容均来自自身领域 — 例如森林的环境音层规格（基础层、风声和野生动物等细节音、单次音效、过渡），用于在音乐方向确定后与之配合 — 绝不提供音乐简报

### 用例 3：动态参数 — 衰减曲线规格
**输入：** "剑挥砍 SFX 需要距离衰减，使其在竞技场不同位置听起来不同。"
**预期行为：**
- 记录事件的距离空间属性：
  - 参数名（例如 `distance` 或 `listener_distance`）
  - 衰减曲线类型（例如对数、线性、自定义）
  - 近/远距离阈值及对应的音量和高频衰减值
- 对请求中未指定的行为（例如竞技场几何体遮挡）进行询问，而非自行假设
- 不编写音频引擎集成代码，不更改音频中间件配置

### 用例 4：命名规范冲突
**输入：** "为近战系统添加一个名为 `SWORD_HIT_1` 的新 SFX 事件。" [上下文中包含 audio-director 的命名规范：`[category]_[context]_[name]_[variant]`，例如 `sfx_combat_sword_swing_01`。]
**预期行为：**
- 识别出 `SWORD_HIT_1` 偏离了上下文中的命名规范
- 不静默注册不合规的名称
- 明确标记该偏差并提供合规替代名（例如 `sfx_combat_sword_hit_01`），指明 `audio-director` 为该规范的负责人
- 仅在用户确认修正后的名称（或明确例外）后才添加该事件

### 用例 5：上下文传递 — 使用音频风格指南
**输入：** 上下文中提供的音频风格指南规定："粗粝、扎实、混响尾音不超过 1.5 秒，参考：The Witcher 3 战斗音频。" 请求："为整套近战战斗创建 SFX 规格。"
**预期行为：**
- 在规格理由中引用"粗粝、扎实"的音色描述
- 按指南将所有混响尾音规格限制在 1.5 秒以内
- 将参考素材（The Witcher 3）记为混音电平和瞬态设计的基准
- 不产出与风格指南矛盾的规格（例如空灵或重度混响处理的规格）；若某个音效似乎需要指南排除的元素，标记给 audio-director，而非自行决定音色方案

## 协议合规性

- [ ] 保持在声明的领域内（SFX 规格、事件定义、混音参数）
- [ ] 将音乐方向请求重定向至 audio-director
- [ ] 返回结构化 SFX 规格（描述、音量范围、空间属性、变体和音高范围、触发/优先级/并发、总线）
- [ ] 不产出音频系统实现的代码
- [ ] 明确标记对既定命名规范或设计文档的偏差，而非静默接受不合规名称
- [ ] 在所有规格输出中引用提供的风格指南和约束

## 覆盖说明
- SFX 规格格式（用例 1）应匹配音频中间件（Wwise/FMOD/内置）所要求的事件 Schema
- 衰减曲线（用例 3）验证 Agent 产出可直接用于实现的参数规格
- 风格指南合规性（用例 5）确认 Agent 读取提供的上下文并据此约束输出
